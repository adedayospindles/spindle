A safe customization layer for the Spindles parent theme.

== Description ==

Spindles Child loads after the parent theme's stylesheets so you can add custom CSS and PHP without editing the parent, which means parent theme updates will not overwrite your changes.

The Spindles parent theme must be installed. Customizer settings are stored per theme, so after activating the child theme, open Appearance > Customize and re-apply your Spindles Design System choices (menus and widgets may also need to be re-assigned).

== Installation ==

1. Install and keep the Spindles parent theme in Appearance > Themes.
2. Upload and activate Spindles Child.
3. Add your custom CSS to the child theme style.css and your PHP to its functions.php.

== Frequently Asked Questions ==

= Do I need the parent theme? =

Yes. Spindles Child does nothing on its own and requires the Spindles parent theme.

= Where do I put custom CSS? =

In the child theme style.css, below the theme header comment. It loads after all parent stylesheets.
